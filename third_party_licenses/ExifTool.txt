# ExifTool — Pentax lens-type table (vendored data)

`photoapp/pentax_lens.py`'s `LENS_TYPES` table is generated from ExifTool's
`Image::ExifTool::Pentax` `%pentaxLensTypes` (ExifTool 13.55), which maps the two-byte Pentax
MakerNote `LensType` code to a lens name. ExifTool does not store this in the image; it is
ExifTool's own compiled data, without which a Pentax RAW's lens can only be shown as a number.

Upstream: <https://exiftool.org/>
