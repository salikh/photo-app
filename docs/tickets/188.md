# 188: Static video thumbnails with a play indicator

- Type: task
- Status: done
- Priority: user request 2026-10-08
- Parent: [184](184.md), depends on [186](186.md)

## What's wanted

Thumb 300 / Small 1000 / Medium 2000 / Huge (full) JPEGs in the existing thumbs tree
(`Thumb/NAME.mp4.jpg`), from one frame ~10% into the clip (skip near-black frames: try a few
offsets and pick the first non-dark one), honoring the rotation tag.

- All sizes are clean frames: the play indicator is **not** burned in (user decision 2026-10-08); it
  is a client-side SVG overlay on every video tile (ticket 192), shown even when the video cannot be
  played.
- Placeholder when ffmpeg is missing or decoding fails: flat dark JPEG of the right aspect (the
  overlay still marks it as a video), so the grid never shows a broken image; failures are recorded (190), not retried
  per request.
- Reuses the downscale-from-larger logic of `thumbs.make()`; crop/rotation/RAW-tuning do not apply.
- On-demand generation produces only the static Thumb (one seek); the rest is background (190).
