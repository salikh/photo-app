# 256: every job logs its details and progress at INFO

- Type: task
- Status: done
- Priority: user request 2026-10-19

`JobQueue._run` logs `job start: #id kind file N (path) target=.. options=..` and
`job done|FAILED: ... in 3.2s [note]` at INFO for every job, so all kinds are covered centrally. The
per-file kinds that run by the thousand (`populate_thumb`, `raw_render`, `video_thumb`, `ai_rate`) log
only their finish at INFO; their start is verbosity 2. Long jobs add their own progress: video
stabilization logs each pass, rescan and scan_dir log what they read (files seen / read, error).
Test: `test_every_job_logs_start_and_finish_at_info`.

Every line about a file job names the photo/video file's path (user request, same day): the start/finish
lines via `file N (path)`, the stabilization pass lines and the finish line of a stabilize via the path too.
