# 070: vlog(1..7) logging in the populate_thumbs tool

- Type: task
- Status: in progress
- Priority: user request 2026-09-22, implement now
- Related: [066](066.md) Background low-priority population of /zoo/Thumbs with dcraw
- Refs: `photoapp/populate_thumbs.py`, `photoapp/thumb_populate.py`

Add `absl.logging.vlog(N, ...)` calls to the populate_thumbs tool (the CLI entry point and
`thumb_populate.py`), so a `--verbosity=N` run gives visibility at the right granularity without
touching the default (non-verbose) output.

## Guideline (as given by the user)

- vlog(5) or vlog(7): an individual file operation that completed normally (finer detail -> 7).
- vlog(3): events worth a user's attention -- progress markers, unexpected-but-handled conditions
  on a file (e.g. a fallback path taken).
- vlog(1): detailed statistics on the whole run or a big part of it.
- Actual errors or anything worth fixing stay at `logging.info`/`.warning`/`.exception` (non-vlog),
  unchanged.
- Main goal: `--verbosity=3` alone should be enough to see what the batch job is doing at a
  granularity of seconds to a minute; everything else scales up/down from there.
