# 121: Recenter loupe image when files/tuning panel is open

- Type: enhancement
- Status: done (resolved 2026-09-25)
- Related: [085](085.md), [094](094.md), [105](105.md)
- Refs: `photoapp/static/loupe.js` (`openFiles`, `closeFiles`), `photoapp/static/style.css` (`.stage`, `.files-panel`)

## Description

When the files/tuning side panel is open (toggled by `I` or the "files" button), it overlays the
right portion of the stage area. The main image (`img.main`) remains centered within the full
stage width, so a significant part of the photo can be hidden behind the panel — especially for
landscape images or narrow viewports.

The image should be recentered within the *visible* portion of the stage (i.e. the area not
covered by the panel) so the photo is fully visible and not obstructed.

## Approach

- When the panel opens, shrink the effective centering area of `.stage` so the image avoids the
  panel's width. This can be done with a CSS class on `.stage` (e.g. `.stage.panel-open`) that
  adds `padding-right` or adjusts the flex container, or by narrowing `img.main`'s `max-width`.
- When the panel closes, restore normal centering.
- The tuning overlay (`img.tuning`) must track the same offset so compare (hover/Shift) still
  aligns pixel-for-pixel with the committed image.
- On mobile (viewport ≤ 699 px), the panel is already full-width, so no offset is needed.

## Implementation

- `.stage.panel-open { padding-right: min(420px, 40%); }` shrinks the flex centering area;
  `img.main` shifts left naturally. The tuning overlay (`position: absolute; inset: 0`) tracks
  the padded content box automatically.
- `openFiles()` adds `panel-open` to `ui.stage`; `closePanelOnly()` removes it.
- Mobile override: `.stage.panel-open { padding-right: 0; }` inside `@media (max-width: 600px)`.
