# 191: API: serve animated thumbnails and the original video

- Type: task
- Status: done
- Priority: user request 2026-10-08
- Parent: [184](184.md), depends on [185](185.md), [189](189.md)

## What's wanted

- Thumbnail endpoint accepts the animated variant (e.g. `?anim=1` or a `.webm` suffix) with correct
  `Content-Type: video/webm` and cache headers; 404 (not 500) when absent so the client falls back
  to the still.
- Original served with HTTP Range support (206, `Accept-Ranges`) and the right MIME type, for the
  loupe `<video>`; large files are streamed, never read into memory.
- Photo/file JSON: `is_video`, `duration`, `has_anim` flags.
