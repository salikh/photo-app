`files.tuning_note` column (migration). `POST /api/photos/{id}/stabilize {level, options?}` (400 for
a non-video / unknown level, 503 when ffmpeg or vidstab is missing) enqueues a `stabilize` job (file =
the Photo's original video, `options` = level + overrides) on `medium_jobs`; the same level already
queued/running dedupes. The handler stabilizes, atomically replaces `<stem>.stabilized-<level>.mp4`,
imports it (`scan.import_single_file`), stores `tuning_note`, links it as a tuning of the original
(`manual_links.link`), drops stale thumbnails of a re-run, and sets `jobs.note` to the progress.
`photo_detail` returns `tuning_note` per file; `/api/config` reports `can_stabilize`.
