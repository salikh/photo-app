# 199: Filter picker dismisses on a click outside; no title on the actions popover

- Type: task
- Status: done
- Priority: user request 2026-10-08
- Refs: `photoapp/static/loupe.js` (`renderFilterPanel`, `openActionsMenu`), `photoapp/static/style.css`

## What's wanted

The loupe's filter-switcher popover should close on a click outside it, with the same light dimming as
the "⋯" actions popover. The actions popover loses its "Actions" title.

## Design

The picker is wrapped in a fixed full-window `.popover-backdrop` (20% black, above the HUD) whose click
closes the picker; the card inside stops propagation and is still placed by `placeNear` (198). Because
the backdrop covers the HUD, the filter tag no longer toggles the picker closed -- a click on it lands on
the backdrop, which closes it all the same. Escape still closes it.
