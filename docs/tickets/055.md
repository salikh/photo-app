# 055: Rating filter buttons (v1)

- Type: task
- Status: open
- Priority: v1, do now (user request 2026-09-21)
- Related: [056](056.md) photos leave the view when their rating stops matching, [057](057.md) counts and shortcuts, [026](026.md), [049](049.md)
- Refs: `photoapp/library.py` (`_FILTER_SQL`), `photoapp/static/app.js` (`FILTERS`, header `select`)

Replace the filter drop-down with a row of buttons for the rating modes used while culling.

## Today

The filter is a `<select>` in the header with seven options (`all`, `unrated`, `rejected`, `picked`,
`rated`, `fav`, `conflict`), stored in the URL (`?filter=`). The server filters (`library._FILTER_SQL`).
There is no "rating == N".

## The modes (the user is not sure which buttons work best; Lightroom's set is thought to be overkill)

The modes named as most useful: **unrated only**, **rejected only**, **rating == N**.

Proposed v1 button row (each a toggle-style button, exactly one active):

`All` · `Unrated` · `Rejected` · `★1` · `★2` · `★3` · `★4` · `★5`

- `★N` means **exactly N stars** (not "N or more"), as asked.
- With `--one_star_is_unrated` ([049](049.md)) there is no `★1` button and `Unrated` also includes 1 star.
- The existing extra filters (`fav`, `conflict`, and "rated at all" / "picked") move into a small
  **More** menu, so nothing is lost but the main row stays short. (Lightroom's full set adds flags,
  colors, metadata and text search; that is what is being avoided.)
- Later options if the row proves too limited: "N or more", several buttons active at once,
  combining with fav. Not part of this ticket.

## Behavior

- The active button is clear at a glance (same accent as the selected state elsewhere); the filter
  stays in the URL so reload and back work; it is kept when moving to another folder (culling several
  folders "unrated" is the main use). The current filter is also shown in the loupe HUD.
- Phones: the row is one horizontally scrollable strip with 44 px buttons, no wrapping onto several rows.
- Dark theme colors from the CSS variables only.
