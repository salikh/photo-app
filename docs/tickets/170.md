## What's wanted

Read the 35mm-equivalent focal length (EXIF 0xA405) and store it, so new scans and `/api/photos/{id}`
carry it.

## Design

- `fileinfo`: `_EXIF_FOCAL_LENGTH_35MM = 0xA405`; `read_lens_metadata` returns it as a fifth value
  (appended, so nothing before it moves); `read_image_metadata` appends
  `focal_length_35mm` to its tuple (now 12); `read_exif_from_tiff` reads it from the Exif sub-IFD
  too, so a PEF gets it.
- `db.py`: migration `ALTER TABLE files ADD COLUMN focal_length_35mm INTEGER;` (nullable; NULL when
  the tag is absent, like the other EXIF columns).
- `scan.py`: `focal_length_35mm` joins `_upsert_file`, both `_scan_files` record dicts/unpackings,
  `import_single_file` and `_apply_move`.
- `library.photo_detail`: select `focal_length_35mm` for the API.
- `tools/archive/catalog.py`: add it to `_EXIF_KEYS`/the unpacking/`--metadata_json_fields=exif`
  help; `tools/archive/README.md` names it.
