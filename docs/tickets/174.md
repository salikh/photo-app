## What's wanted

A way to give the app a Google API key for the Gemini Flash-Lite model, and to name the model.

## Design

- Key lookup order: `$GEMINI_API_KEY`, then the file named by `--gemini_api_key_file` (default
  `<state_dir>/gemini_api_key`, stripped). **No `--gemini_api_key` flag**: a command-line value
  shows up in `ps` and a TOML value in a file that may be shared. Document `chmod 600`.
- `--ai_model` (default `gemini-flash-lite-3.5`), part of `Settings`.
- `Settings.gemini_api_key()` returns the key or `None` (never raises, never logs the key).
- The key file is not in the pictures dir, not in git; state-dir backups should be told about it
  (`docs/operations.md`).
