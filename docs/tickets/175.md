## What's wanted

A versioned store for prompts — ad hoc / content-hashed, no linear version history.

## Design

- A prompt is a plain file in the checkout (`photoapp/prompts/<name>.md`, plus
  `<name>.schema.json` for the response schema, see 176) so it is edited like code.
- `ai_prompts.load(name)` reads the files and returns `Prompt(name, text, schema, hash)`;
  `hash` = first 16 hex chars of sha256 over text + `\n---\n` + canonical (sorted-key) schema JSON.
- A new table `ai_prompts(hash PRIMARY KEY, name, text, schema, created_at)` (migration);
  `ai_prompts.register(conn, prompt)` is idempotent (`INSERT OR IGNORE`), so every hash a cached
  response refers to can be looked up later, even after the file was edited.
- The model name is **not** part of the prompt hash (it is a separate cache-key component, 179).
