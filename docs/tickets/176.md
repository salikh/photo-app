## What's wanted

A prompt for Gemini Flash-Lite, sent together with a Medium (2000 px long edge) rendition of the
photo, asking structured numeric rating questions, e.g. "how sharp is this image? 0 = very blurred,
5 = very sharp".

## Design

Questions (every one an integer; the scale is spelled out in the prompt **and** enforced by the
schema's `minimum`/`maximum`):

| key | range | meaning |
|---|---|---|
| `sharpness` | 0..5 | 0 very blurred, 5 very sharp |
| `composition` | 0..5 | 0 very imbalanced or bad looking, 5 very well balanced |
| `exposure` | 0..5 | exposure of the *main element*: 0 over/underexposed by 3+ stops, 5 correct |
| `has_people` | 0..1 | 0 no people, 1 there are people |
| `faces` | -2..2 | -2 very weird/unnatural faces, 0 neutral or no faces, 2 very natural, good-looking expressions |
| `subject_interest` | 0..5 | 0 nothing of interest, 5 compelling subject/moment |
| `color` | 0..5 | 0 muddy/garish, 5 pleasing colour and tonal range |
| `technical_flaws` | 0..5 | 0 none, 5 severe (heavy noise, motion blur, blown highlights, lens dirt, tilted horizon) |

The prompt says: the photo is a downsized rendition (judge composition and content, not pixel-level
detail beyond what 2000 px can show), answer only with the JSON object, use `0` for `faces` when no
people are visible. The schema is a Gemini `responseSchema` (OpenAPI subset: `type`, `properties`,
`required`, `minimum`, `maximum`); the keys are the contract with 178's scoring function.
