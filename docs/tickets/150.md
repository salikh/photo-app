# 150: Files panel shows each file's byte size

- Type: task
- Status: in progress
- Priority: user request 2026-09-29
- Refs: `photoapp/static/loupe.js` (`openFiles`, the per-file `meta` row), `photoapp/static/util.js`
  (`fmtBytes`, already used by `pages.js`'s `usagePage`), `photoapp/library.py` (`photo_detail`,
  already selects `bytesize` per file)

## What's wanted

In the loupe's Files panel, show each file's byte size, formatted with a B/KB/MB unit suffix and
typically 2 significant digits (e.g. 2613000 bytes → "2.5 MB").

## Design

No backend change: `library.photo_detail`'s `files` rows already include `bytesize`. `util.js`
already has `fmtBytes(n)` (used by `pages.js`'s Thumbnails page) — one decimal place, dynamic
B/KB/MB/GB/TB unit — which gives exactly "2.5 MB" for the example in the ticket and, for the
common range of real photo file sizes (single-digit-to-low-hundreds MB), 2-3 significant digits;
reused as-is rather than writing new formatting logic for the same thing twice. `openFiles`'s
per-file meta row (`${f.width || '?'}×${f.height || '?'}  ${f.path}`) gains the size.
