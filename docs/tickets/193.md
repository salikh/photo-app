# 193: UI: video playback in the loupe

- Type: task
- Status: open
- Priority: user request 2026-10-08
- Parent: [184](184.md), depends on [191](191.md)

## What's wanted

Loupe shows a `<video controls>` streaming the original through Range requests. If the browser
cannot play it (`canPlayType` / `error` event: AVI, WMV, old codecs), show the Medium still, the
animated thumb if present, and a "download original" link with a short explanation. RAW tuning,
crop and rotation controls are hidden for videos; rating, tags, trash, move and keyboard
navigation work as for stills (arrow keys must not be swallowed by the player).
