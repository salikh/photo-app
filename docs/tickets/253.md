# 253: Stabilize a selection of videos from the grid

- Type: feature
- Status: done
- Priority: user request 2026-10-19
- Parent: [246](246.md)

Select mode in the grid gets a `Stabilize` button in the selection bar whenever the selection holds
a video. It opens the same level popover as the loupe (titled with the count) and files one
`stabilize` job per selected video on the medium queue (`POST /api/photos/stabilize {ids, level,
options}`); non-video Photos are skipped and reported in the toast, not an error. The queue runs them
one at a time (single medium worker).
