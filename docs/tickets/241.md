# 241: grid magnification levels

- Type: feature
- Status: done
- Priority: user request 2026-10-13

## Request

Several magnification levels in the grid: the current one is the smallest, plus three bigger steps.
No upsampling. Shortcuts '+' / '-'; also catch the standard zoom gestures (Ctrl+scroll, pinch).

## Design (decided without asking; adjust if wrong)

- `photoapp/static/gridzoom.js`. Tile minimum width (CSS px), desktop 150 / 230 / 340 / 500, phone
  (<= 600 px) 110 / 150 / 260 / 380; it sets `--cell`. Level persists in localStorage (`gridLevel`).
- No upsampling: the thumbnail is `Thumb` (300 px long edge) while the tile's real width x
  devicePixelRatio is <= 300, else `Small` (1000 px). The width is measured from the laid-out tile
  (auto-fill stretches tiles past the minimum); a ResizeObserver re-evaluates on window resize.
  A 2x display therefore already uses Small from level 1 (230 x 2 > 300).
- Inputs, only while a grid is shown (not in the loupe, which has its own zoom): `+`/`=` and `-`/`_`;
  Ctrl+wheel (a trackpad pinch is Ctrl+wheel in Chrome; browser page zoom is suppressed there);
  two-finger pinch on touch screens (`touch-action: pan-x pan-y` on the grid). Levels clamp at both ends.
- Note: a Small thumbnail that does not exist yet is rendered on first request (slow on the NAS for
  2021-2025 folders); the existing retry logic covers the wait.
- Tests: `test_grid_plus_minus_steps_through_four_levels_without_upsampling`,
  `test_grid_ctrl_wheel_zooms_and_does_not_open_help_or_browser_zoom`. Pinch is not covered by a test.
