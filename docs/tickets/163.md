## What's wanted

`python -m photoapp.backfill_exif` is the existing way to fill old rows without a full rescan. Make
it work for PEF and fill everything ticket 161 can extract, so the real library's 147 PEF rows are
populated at once rather than only after the next scan.

## Design

- `backfill`: instead of `Image.open` + `fileinfo.read_camera_metadata`, call
  `fileinfo.read_image_metadata(path)` (which now falls back to the TIFF IFD reader for PEF) and
  write **all** EXIF columns — `exif_date`, `aperture`, `shutter_speed`, `iso`, `focal_length`,
  `camera_make`, `camera_model`, `lens_model`. A file whose returned EXIF is entirely `None` is
  still `unchanged` (a screenshot/PNG with no EXIF), exactly as before.
- `find_unbackfilled` keeps its current selection (no camera metadata yet), which every PEF row
  matches; widening it to "any field missing" is deliberately not done (it would newly match
  thousands of genuinely EXIF-less JPEGs every run for no benefit).
- `docs/operations.md`: the section now says the command fills the full EXIF set and names PEF.
