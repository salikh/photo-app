# 240: crop shade misaligned right after a swipe to the next photo

- Type: bug
- Status: done
- Priority: user request 2026-10-12

## Problem

After swiping to the next photo, the crop shade was drawn off the picture (shifted by the swipe
offset); opening the files pane re-laid it out and fixed it.

## Cause

On a swipe, `resetDrag()` clears the image's `translateX` with a 0.18 s CSS transition, and `go()` then
positioned the shade from `img.getBoundingClientRect()` -- the half-eased box -- and nothing
re-measured afterwards.

## Fix

`show()` switches the image's transition off for a frame so the offset is gone before the shade is
positioned. Test: `test_crop_shade_is_aligned_right_after_a_swipe_to_the_next_photo` (fails without the fix).
