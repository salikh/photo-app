## What's wanted

New module `photoapp/video.py`: the only place that runs `ffmpeg`/`ffprobe` (subprocess, argument
lists, never a shell). Decided: system ffmpeg (no pip wheel).

- Binary lookup (`--ffmpeg_path`/`--ffprobe_path` flags, default `$PATH`), cached availability check.
- `probe(path)` -> JSON dict; `run(args, timeout)` with `nice`, a hard timeout, stderr captured into
  the error; killed process group on timeout.
- Graceful degradation: ffmpeg missing => videos are still indexed and listed, thumbnails fall back
  to the placeholder (188); a single warning at startup, not per file.
- `deploy.sh`: dependency check for `ffmpeg`/`ffprobe` (print `apt install ffmpeg`; `--install-deps`
  runs it); `docs/operations.md` and `README` mention it.
- Tests use a tiny synthetic clip generated by ffmpeg itself, skipped when ffmpeg is absent.
