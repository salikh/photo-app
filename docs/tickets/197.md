# 197: Loupe: the Files panel ('i') showed two images for a video

- Type: bug
- Status: done
- Priority: user report 2026-10-08
- Parent: [184](184.md); Refs: `photoapp/static/loupe.js` (`setVideoShown`), `photoapp/static/style.css`

## Report

Viewing a video in the loupe and pressing `i` showed two images (a small thumbnail plus the video
element). Expected: only the video element, centered in the space left of the Files panel.

## Cause

The Medium still (`img.main`) stays in the stage under the player. `.stage.panel-open` pads the stage
so the still re-centers beside the panel, while the absolutely positioned player was re-laid out by its
own rule: two differently placed images.

## Fix

While the player is shown the stage gets `video-shown` and the still is `visibility: hidden` (the
player has the still as its poster anyway). The still comes back for the fallback (unplayable video).
The player fills the stage minus the panel (`right: var(--files-panel-w)`), full width on mobile where
the panel covers the stage. e2e test in `tests/e2e/test_video_ui.py`.
