# 237: Pinch zoom from the plain loupe view jumps the image

- Type: bug
- Status: done
- Priority: user request 2026-10-12
- Related: [060](060.md) (zoom), `photoapp/static/zoom.js`

## What's wanted

"Try to fix the transition from plain loupe view to zoomed view to avoid a sudden jump of image on
pinch zoom gesture. This may be related to how the 'files' pane affects centering of the image.
Currently when pinch-zooming an image in the center, the zoomed view shows the left-hand side of the
zoomed image."

## Todo

- [x] reproduce (files pane open vs closed, touch pinch) and find the cause
- [x] fix; regression test

## Result

Cause: the files panel shifts the fitted photo left (`.stage.panel-open { padding-right: 420px }`
centers it in the area beside the panel), but `zoom.js` assumed the photo was centered in the whole
stage, so the first frame of a pinch moved it sideways by half the panel width (the zoomed view then
showed the photo's left side), and `.stage.zoomed` dropped the padding on top of that. Fix: zoom.js
measures the usable area as the stage minus its `padding-right`; the zoomed stage keeps that padding
(the photo never slides under the panel); opening/closing the panel while zoomed re-clamps
(`zoom.relayout()`). Test: `test_pinch_start_does_not_move_the_image_with_the_files_panel_open`.
