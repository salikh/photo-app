- Type: task

  (`test_files_panel_shows_camera_metadata`)

## What's wanted

The per-file metadata line in the Files pane shows the lens used, alongside the existing camera
make/model, focal length, aperture, shutter speed, ISO and date.

## Design

- `cameraMetaText(f)` gains `f.lens_model` as one more part, right after the camera (`formatCamera`)
  and before focal length — the natural reading order ("body + lens, focal length, exposure"). It is
  already `null`-filtered, so a file with no lens tag shows nothing new, and the line is otherwise
  unchanged.
- No new element, CSS, or endpoint: `photo_detail` (ticket 157) already carries the field, and the
  existing `cameraMetaText(f) ? el('div', {class: 'meta', ...})` render site (loupe.js:1098)
  handles the whole line.
