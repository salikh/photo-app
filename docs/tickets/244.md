# 244: loupe never shows another photo's render while the next one loads

- Type: bug
- Status: done
- Priority: user request 2026-10-19

After a swipe or a click on another photo the loupe kept painting the previously loaded render (an `<img>`
shows its old picture until the new URL has arrived). `show()` now hides the main image
(`visibility: hidden`) whenever its URL changes and the image's `load` handler reveals it; the
Medium/Huge swaps within one photo (zoom in/out) are unaffected.
