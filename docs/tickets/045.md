# 045: Swipe left/right to navigate pictures in a folder

- Type: task
- Status: open
- Parent: [043](043.md) Mobile UI
- Depends on: [044](044.md) Responsive layout, [027](027.md) Loupe view
- Refs: user request (b)

In the loupe, a horizontal swipe moves to the next/previous picture in the current folder
ordering (same order and preloading as the arrow keys).

Proposed mapping: swipe left = next picture, swipe right = previous (the usual photo-gallery direction).

## Todo

- [ ] Gesture handling with Pointer Events (one code path for touch, pen and mouse drag), distinguishing horizontal from vertical swipes by dominant axis and a distance/velocity threshold
- [ ] The image follows the finger and animates to the neighbor; snap back when below threshold
- [ ] Reuse the loupe's preloading (next 3, previous 1) so a swipe shows an image immediately
- [ ] Behavior at the first/last picture (rubber-band, no wraparound)
- [ ] Do not conflict with pinch-zoom and with panning a zoomed image (swipe only when not zoomed, or at the pan edge)
- [ ] URL-hash state keeps working (reload and back land on the same picture)
- [ ] Test on a real phone over the LAN
