## What's wanted (as given)

A "stabilize" action on the loupe toolbar, shown only on videos. A click asks for a quick parameter
choice in a modal ("strong" vs "weak" amplitude, more explicit parameters possible later) and, on
confirmation, queues a task of **medium priority** (below interactive thumbnail rendering and a
directory rescan, above batch thumbnail rendering). The task is ffmpeg 2-pass stabilization
(`vidstabdetect` + `vidstabtransform`). The result lives next to the original with a
`.stabilized-<level>.` infix and is linked to the original as a **tuning**. The Files pane offers
which tuning (original or stabilized) is shown on thumbnails and for playback, and offers to delete
either (eventually the unstabilized original too). Quality roughly like the original but somewhat
compressed; a format that plays on Android / iOS / web browsers (so not necessarily the original's).
vidstab options are easy to tune (and may become modal options later); the options used are kept as a
single human-readable description and shown in the Files pane. Running the same level again overwrites
its file; a different level makes a second file.

## Decisions (made without asking; all easy to revisit)

- **Queue**: a third `JobQueue` (`app.state.medium_jobs`), one worker, nice 10. Interactive work
  (`app.state.jobs`: video/RAW stills) keeps nice 0 and the rescan keeps its elevated thread; the
  batch populator stays at nice 19 / idle I/O.
- **Output**: H.264 (High, yuv420p) + AAC in MP4 with `+faststart`, CRF 23 / preset medium, same
  resolution and frame rate, even dimensions; output named `<stem>.stabilized-<level>.mp4` in the
  original's directory (so a `.mov` original gives an `.mp4` tuning).
- **Link**: a durable manual link (role `tuning`) to the Photo's original video, like any other manual
  link (survives rescans; mirrored in `manual_links.jsonl`).
- **Description**: `files.tuning_note` (e.g. `stabilized (strong): vidstab shakiness=8 smoothing=30 ...`)
  plus the same text in the MP4's `comment` tag. DB is the source for the Files pane.
- **Source**: always the Photo's original video (never a stabilized file).
