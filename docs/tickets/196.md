# 196: Loupe "⋯" button opens a modal actions menu; Export moves into it

- Type: task
- Status: done
- Priority: user request 2026-10-08
- Refs: `photoapp/static/loupe.js` (`renderHud`, `openActionsMenu`), `tests/e2e/test_ui.py`

## What's wanted

The "⋯" button in the loupe HUD acted immediately (flush this photo's thumbnails). It should open a
modal menu to pick an action from, and the dedicated "export" button should become an item of that menu.

## Design

- "⋯" (class `debug-menu`, title "more actions") opens a modal built on the existing
  `confirm-modal`/`confirm-card` shell: title "Actions", one button per item (label + hint), a Close
  button; a click outside, Close or Escape dismisses it without acting; picking an item closes the menu
  first, then runs the action.
- Items today: **Export…** (hidden for a video, which export skips -- ticket 195) and **Flush
  thumbnails** (the old behaviour). New per-photo actions are added in `actionsMenuItems()`.
- The prominent "⚠ fix thumbnail" button shown after a failed thumbnail load stays a direct button
  (it is the repair, not a menu).
