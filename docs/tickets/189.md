## What's wanted

Short preview clips: N=8 fragments of 1 s taken at the centers of 8 equal slices of the duration,
concatenated into one muted VP9 WebM; a video shorter than 8 s is used whole. Sizes: Thumb 300 px
(12 fps) and Small 640 px (15 fps) long edge; no Medium/Huge animation. No audio, no play badge
(it is an animation, the static one carries the badge).

- Storage next to the static ones: `Thumb/NAME.mp4.webm`, `Small/NAME.mp4.webm`; animated sizes are rows of the same `thumbs` table named `AnimThumb`/`AnimSmall`
  (`thumbs.ANIM_SIZES`, deliberately outside `SIZES`; no schema change, `clear`/`move_thumbnails`
  cover them); `source` records the recipe (`anim-v1`). Measured on a real 665 MB clip: 2.4 s + 4.4 s,
  90 KB + 275 KB.
- Generation with a single ffmpeg invocation using input-side seeks per segment (`-ss` before `-i`,
  concat via filter_complex) so long NAS files are not read end to end; bounded bitrate/CRF.
- Parameters (N, fragment length, sizes, fps) are constants in one place; changing them invalidates
  by a recorded recipe version so the populator can regenerate.
