# 192: UI: video tiles in the grid and filmstrip

- Type: task
- Status: open
- Priority: user request 2026-10-08
- Parent: [184](184.md), depends on [191](191.md)

## What's wanted

Grid shows the static thumb (with its burned-in indicator) plus a duration badge. When an animated
thumb exists it plays (muted, looped) on hover; on touch devices on tap-hold or when the tile is
the focused one; never autoplays the whole grid (CPU, bandwidth). Falls back to the still when the
animation is missing. Filmstrip shows the still + duration.
