# 234: "Delete" button in the loupe's bottom bar for a rejected photo

- Type: task
- Status: done
- Priority: user request 2026-10-12
- Related: [072](072.md) (trash), [082](082.md) (per-file trash)

## What's wanted

"When viewing a rejected photo in loupe, have 'Delete' button in the lower bar, which immediately
applies trash action just to the current image. Make sure the button is there only when viewing a
rejected photo."

## Result

The HUD bar (`renderHud`) has a red **Delete** button only while the shown photo is rejected (it
appears/disappears with the rating, e.g. after X or undo). It posts `/api/photos/trash` with just
that photo's id (the server re-checks it is rejected, moves every file and sidecar to `.trash/`), no
confirmation step, toasts "moved to trash", removes the photo from the view and moves on to the
next one. Test: `test_loupe_delete_button_only_on_a_rejected_photo_and_trashes_just_it`.
