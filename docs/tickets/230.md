## What's wanted (as given)

"Create a pair of hotkeys: one for storing the adjustments ("save" = s), and another to apply saved
adjustments ("apply" = a)."

## Design

- In the viewer, **S** stores the shown file's adjustments in an in-memory clipboard (also kept in
  `sessionStorage` so a reload keeps it); **A** applies the stored adjustments to the shown file and
  saves them (the same POST as the panel's Save, so thumbnails regenerate and the revision bumps).
- "Adjustments" are the file's per-file rendering settings that have sliders: the **edit document**
  for a non-RAW still (epic 222) or the **RAW settings** for a RAW file (085). Crop and rotation are
  composition, not tone, and are not copied. A clipboard of one kind is not applied to the other
  (toast says why): edits do not make sense on a RAW and vice versa.
- What gets stored is what is *on screen*: pending (unsaved) slider values if the Files panel has
  them for this file, else the saved ones. Applying replaces the target's adjustments wholesale
  (like Save) and drops any pending values for it.
- Storing an unadjusted file stores "nothing", so applying it resets the target to default — a quick
  reset; the toast says "stored: no adjustments".
- Toasts confirm each action; nothing happens for a video or a file with no applicable kind.
- No conflicts: `s`/`a` are unused in the viewer (Shift+A is a *browse* filter). Listed in the help
  overlay (`h`).
