# 190: Background population of video thumbnails

- Type: task
- Status: open
- Priority: user request 2026-10-08
- Parent: [184](184.md), depends on [188](188.md), [189](189.md)

## What's wanted

Teach `thumb_populate.py` about videos: serialized (one ffmpeg at a time), `nice`/low priority,
per-video timeout (e.g. 5 min), and respects the existing load/memory thresholds. Order: static
Thumb, Small, Medium, Huge, then animated Thumb, Small. Failures (decode error, timeout) are
recorded with the reason and a retry-after so a broken file is not retried on every pass; a manual
"regenerate" path clears the record. ~770 videos, many >100 MB on a NAS: measure and document the
time per video and total on the real library (read-only, scratch thumbs dir).
