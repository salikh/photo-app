# 203: Bug: AnimSmall cut videos of 60-75 s

- Type: bug
- Status: done
- Priority: user report 2026-10-09
- Parent: [184](184.md); follows [201](201.md)

## Report

`AnimSmall` should not cut the video for lengths up to 75 s.

## Cause and fix

Ticket 201 used the whole clip only up to 60 s; a 60-75 s clip was re-assembled from five shrunken
fragments (a concatenation of five separately seeked inputs, not one continuous encode). Five 15 s
fragments cover exactly 75 s, so the whole-clip limit is now 75 s (`ANIM_SPEC["AnimSmall"]`): such a clip
is encoded as one continuous, uncut clip; a longer one gets the five 15 s fragments. The `AnimSmall`
recipe is `anim-v3`, so every `AnimSmall` made before (v1 and v2) is invalidated and remade by the
populator (`video_thumbs.invalidate_stale`). `AnimThumb` is untouched.
