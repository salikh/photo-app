# 046: Swipe up/down to edit the rating

- Type: task
- Status: open
- Parent: [043](043.md) Mobile UI
- Depends on: [045](045.md) Swipe navigation, [029](029.md) Rating API, [030](030.md) Activity log and undo
- Refs: user request (c); docs/reqs/photo-manager-requirements.md (Rating and flags)

A vertical swipe in the loupe changes the current Photo's rating and writes it to XMP through the
normal rating API. Ratings use the combined value in [-1, 5].

Proposed mapping (needs a quick confirmation from the user): swipe up = one step up, swipe down =
one step down along -1 (reject), 0 (unrated), 1..5 stars. It clamps at both ends: no wraparound
from 5 to reject. One swipe = one step, so a long drag does not skip levels.
