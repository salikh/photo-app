## Design

An export or an upload of a file that has edits uses the baked full-size (Huge) render instead of the
original bytes; a file without edits behaves exactly as before (original bytes, EXIF intact).
EXIF of the original is carried into the rendered JPEG as for a RAW export (`exif_write.py`).
The rendered JPEG's quality is the existing export quality. The original file is never modified.
