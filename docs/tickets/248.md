- Type: task

- Parent: [246](246.md); Refs: `photoapp/video.py`

`photoapp/video_stabilize.py`: `LEVELS` (preset name -> vidstab parameter dict, easy to edit),
`describe(options)` (the human-readable string), `stabilize(tools, src, dest, options, progress)`.
Pass 1 `vidstabdetect` into a temp dir (`.trf`), pass 2 `vidstabtransform` + light `unsharp`, encode
H.264/AAC MP4 (`-movflags +faststart`, `-pix_fmt yuv420p`, CRF 23), write to `dest + ".part"` then
rename (a failed or killed run never leaves a half file under the final name). `available(tools)`
checks that the ffmpeg build has the vidstab filters. Timeouts scale with duration. Tests with a
synthetic clip (skipped without ffmpeg).
