## What's wanted (as given)

Automated photo ranking: send the Medium rendition of a photo with a prompt to Google's Gemini
Flash-Lite model, get structured numeric answers (sharpness, composition, exposure of the main
subject, face naturalness, people present, ...), turn them into one number with an easily
modifiable, content-versioned function, show it in the Files pane and sort by it. Prompts are
stored content-hashed; responses are cached keyed on the prompt hash so an unchanged prompt never
re-sends a picture, while a changed prompt (or model) does.

## Design overview (detail in each child ticket)

- **Two independent content hashes decide what is recomputed**:
  - *prompt hash* (prompt text + response schema + model) is part of the **response cache key** →
    a changed prompt means a new request to Gemini (network, costs money);
  - *score-function version* (hash of the scoring module's source) is stored next to each computed
    score → a changed function means a **local recomputation from the cached raw answers**, no
    network.
- **Secrets**: API key from `$GEMINI_API_KEY` or a key file (`--gemini_api_key_file`, default
  `<state_dir>/gemini_api_key`), never a command-line value or a checked-in config key. The model
  name is a flag (`--ai_model`, default `gemini-flash-lite-3.5`).
- **Prompt store**: the prompt lives as a plain file in the repo (`photoapp/prompts/rating.md` +
  `rating.schema.json`), so editing it is a normal edit; each use registers it by content hash in
  an `ai_prompts` table, so a cached response can always be traced to the exact text that made it.
- **Job**: `ai_rate` (file-scoped) on the on-demand queue; handler = cache lookup → (miss) send the
  Medium thumbnail → store the answers → compute and store the score.
- **UI**: an "AI Rate" button next to Export (selection, else everything in view), a line in the
  Files pane, and a "by AI rating" sort.
- Tests never touch the network: the Gemini client takes an injectable transport.

## Non-goals

- Writing the AI rating into XMP sidecars or the star rating (display and sort only).
- Batch/offline Gemini APIs; one request per picture.
- A UI for editing prompts (they are files in the checkout).
