# 117: Multi-state filter buttons cycling between =, >=, <= and 3-column filter selector in loupe

- Type: task
- Status: open (filed 2026-09-25)
- Related: [015](015.md), [016](016.md) (rating filters), [097](097.md), [098](098.md)
- Refs: `photoapp/static/index.html`, `photoapp/static/loupe.js`, `photoapp/static/app.js`

## What's wanted

Make each star filter button (`*1` .. `*5`) behave like a multi-state cycle:
- Default state: "all"
- Click on `*1` -> filter state `=1`
- Click again on `*1` -> filter state `>=1`
- Click again on `*1` -> filter state `<=1`
- Click again on `*1` -> filter state `=1`
- Clicking a different star button (e.g. from `=1`, `>=1`, `<=1` to `*2`) switches directly to `=2`.

In the Loupe view filter selector:
- Create a 3-column selection table/grid for each star value:
  - Column 1: `<= N`
  - Column 2: `= N`
  - Column 3: `>= N`
