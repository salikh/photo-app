# 112: Add sliders for additional raw parameters under a collapsible section

- Type: task
- Status: open (filed 2026-09-25)
- Related: [085](085.md), [102](102.md), [109](109.md)
- Refs: `photoapp/raw_settings.py`, `photoapp/previews.py`, `photoapp/static/rawTuning.js`, `photoapp/static/loupe.js`, `photoapp/api.py`

## What's wanted

Both LibRaw and its WASM version have quite a few DNG conversion parameters, so surface more tunable parameters to the user.
2 or 3 most important ones should be visible immediately (as it is now), and the rest should be hidden under a collapsible section / "zipper".

Candidate parameters from LibRaw / LibRaw-Wasm:
- Half-size demosaicing / fast preview mode
- Demosaicing algorithm selection (e.g. AHD, DCB, VNG, etc.)
- Noise reduction / chromatic aberration correction
- Saturation / contrast / tone curves (if available in bindings)

## Scope note

Any new parameter exposed must follow the epic 102 / ticket 106 & 109 rule:
Keep exact parameter parity between server-side `previews._postprocess_kwargs` and client-side `rawTuning.mapSettings`, verified on real DNG Bayer data.
In `loupe.js`, keep the primary 2-3 sliders directly visible and put advanced sliders inside a collapsible `<details>` / zipper element.
