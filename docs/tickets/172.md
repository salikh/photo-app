## What's wanted

The focal length in the per-file metadata line shows the 35mm full-frame equivalent in parentheses:
`35mm (52mm)`.

## Design

- `formatFocalLength(mm, mm35)`:
  - both present → `` `${mm}mm (${mm35}mm)` ``;
  - only the real focal length → `35mm` (unchanged);
  - only the equivalent → `52mm` (no stray parentheses).
  Rounding to whole millimetres as today.
- `cameraMetaText` passes `f.focal_length_35mm` as the second argument; nothing else on the line
  changes, and `null`-filtering still drops the whole part when both are absent.

## Outcome

Landed. `formatFocalLength(mm, mm35)` returns `35mm (52mm)` when both are present, `35mm` when only
the real length is, `52mm` when only the equivalent is; `cameraMetaText` passes
`f.focal_length_35mm`. The e2e `test_files_panel_shows_camera_metadata` now sets
`focal_length = 50, focal_length_35mm = 75` and asserts `50mm (75mm)` (passes).
