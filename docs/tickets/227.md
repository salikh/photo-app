## Design

- Order (223): decode + EXIF orientation → crop → rotation → downscale → LUT edits → monochrome →
  unsharp → encode. `_open` already returns the oriented/cropped/rotated image; the edit stage runs
  **in `save()` after `thumbnail()`** (sizes below Huge) or on the full image (Huge), so sharpening
  sees the output resolution and its radius is `radius% * long_edge` of that output.
- `make`'s "downscale from a cached larger size" shortcut already skips re-applying rotation
  (`source_rotation`); do the same for edits: a size derived from a cached larger one (which already
  contains the edits) must **not** re-run the LUT, and unsharp is the exception — a Small derived
  from an edited Huge is already blurred by the resize and should get its own sharpen at the output
  size. Simplest correct rule: tone/mono edits are never reapplied to a derived size; sharpen is
  always applied at the final size (cheap at <=Medium). Test both.
- Huge for an edited JPG is no longer "serve the original": `api.py`'s `size == "Huge"` shortcut for
  non-RAW files must fall through to the render path when the file has edits (as it already does for
  a rotated file), rendering once to `Huge/…` (cached, ~0.5-1.3 s).
- An unedited file takes today's code path byte for byte (no regression; assert in a test).
- Thumbnail invalidation reuses `thumb_rev` (as raw settings do) and the grid/filmstrip cache-bust
  from ticket 110.
- Docs: `docs/design/thumbnails.md` gets an "Edits (epic 222)" section.

## Outcome

Landed, with one change to the design above: an edited file is **never derived from a larger cached
size** (`make` ignores cached larger sizes when `edits` is set; one decode per size from the original).
That removes every "don't apply twice" rule at the cost of ~0.25 s per size. Edits are applied in
`thumbs.save` via `resize_and_edit` after the downscale; Huge's original-file shortcut is skipped for
an edited file; `thumbs.ensure` loads the file's edits itself, so the populator and export get them
for free. Design recorded in `docs/design/thumbnails.md`. Tests: `tests/test_edits.py`.
