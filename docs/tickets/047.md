# 047: Dark theme

- Type: task
- Status: open
- Depends on: [026](026.md) Folder browser and grid, [027](027.md) Loupe view (the pages it themes)
- Related: [044](044.md) Mobile layout
- Refs: user request

The app uses dark theme colors throughout. Photos are judged on screen, so the surrounding UI
should be dark and neutral (no bright chrome around the image, no color cast).

Design rule: all colors are CSS custom properties defined once in `photoapp/static/style.css`
(`:root`); pages and components use the variables and never hard-coded colors. This keeps the
theme in one place.
