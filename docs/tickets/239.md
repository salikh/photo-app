# 239: tentative Medium rendering while editing

- Type: task
- Status: done
- Priority: user request 2026-10-12
- Related: [094](094.md), [107](107.md), [235](235.md)

## What's wanted

When changing edit or RAW parameters, update the Medium view immediately with the tentative
parameters, without saving. Changing the photo (next/prev) forgets the changes and reverts to the
saved parameters.

## Result

Ticket 107 showed the provisional render only while hovering the sliders or holding Shift (useless
on an iPad). Now the provisional render is shown as soon as any open control differs from the saved
value (`dirtyFiles` in loupe.js); **holding Shift shows the saved rendering** to compare; Discard,
Save, closing the panel or moving to another photo drops it (`discardPending`). Nothing is stored
until Save. Tests: `test_unsaved_changes_show_in_the_medium_view_and_shift_compares_with_saved`,
`test_tentative_edit_shows_at_once_and_is_forgotten_on_next_photo`.
