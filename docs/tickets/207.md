# 207: EXIF in exported JPEGs

- Type: feature
- Status: open
- Priority: user request 2026-10-10
- Parent: [205](205.md)

## What's wanted

Exported JPEGs currently carry no EXIF, so Google Photos (and any viewer) would date them wrongly. Copy metadata from the source (RAW via rawpy/metacache, JPG from the original) when rendering the export.
