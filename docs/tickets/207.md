# 207: EXIF in exported JPEGs

- Type: feature
- Status: done
- Priority: user request 2026-10-10
- Parent: [205](205.md)

## What's wanted

Exported JPEGs currently carry no EXIF, so Google Photos (and any viewer) would date them wrongly. Copy metadata from the source (RAW via rawpy/metacache, JPG from the original) when rendering the export.

## Todo

- [x] Fields: DateTimeOriginal (+ offset), make/model, lens, focal length (+35mm equivalent, epic 169), aperture, shutter, ISO, exposure bias, white balance, ICC profile / colour space.
- [x] Orientation: reset to normal when rotation is baked into the pixels. No maker notes, no embedded thumbnails.
- [x] GPS only when ticket 208's flag is set; the writer takes a `include_gps` argument (default False).
- [x] Pure-Python writer (piexif or Pillow EXIF; exiftool is not installed). Tests with synthetic and real DNG/JPG (`REAL_DNG`).

## Done

`photoapp/exif_write.py`: EXIF built from the `files` row (+ exposure bias, white balance, GPS from the source), spliced into the JPEG without re-encoding; ICC untouched; orientation never written (pixels are upright). `export_file` calls it for every export. `tests/test_exif_write.py`.
