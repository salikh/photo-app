## Result (2026-09-21)

Sample: 593 real sidecars copied outside the repo (500 random, all 8 rare naming styles, and every
file with `dc:subject`, an xpacket wrapper, an element-form rating, `lr:hierarchicalSubject` or no
rating). Run with `XMP_SAMPLE_DIR=<dir> pytest tests/test_xmp_real_sample.py`. All pass:
no-op edits byte-identical, every edit verified, add/remove tag and rating restore byte-identical.
The sample found two real bugs, both fixed with regression tests: a `dc:subject` whose prefix is
declared on the element itself was not found again, and in files with several `rdf:Description`
blocks a rating could be added to the wrong block.
One accepted difference: removing the last tag from a self-closing `<rdf:Description/>` leaves an
equivalent `<rdf:Description></rdf:Description>`.
