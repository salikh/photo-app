# 161: Fallback EXIF reader for RAW files Pillow cannot open (PEF)

- Type: task
- Status: open
- Priority: user request 2026-09-30
- Related: Epic [160](160.md); [162](162.md) (re-extraction of old records), [163](163.md)
  (backfill that calls this)
- Refs: `photoapp/fileinfo.py` (`read_image_metadata`, `read_exif_date`, `read_camera_metadata`,
  `read_lens_metadata`, `parse_exif_date`, `_exif_rational_to_float`, `_exif_str`),
  `PIL.TiffImagePlugin.ImageFileDirectory_v2`

## What's wanted

Item of epic 160: when a RAW file's EXIF cannot be read because Pillow cannot open it (PEF), read
the same EXIF fields from the file's TIFF IFDs instead, so `read_image_metadata` returns real
values for date, aperture, shutter speed, ISO, focal length, camera make/model and lens.

## Design

- New `fileinfo.read_exif_from_tiff(filepath)` returning
  `(exif_date, aperture, shutter_speed, iso, focal_length, camera_make, camera_model, lens_model)`,
  or all `None` if the file is not a readable TIFF IFD. It:
  - reads the 8-byte header, picks endianness from `II`/`MM`, reads IFD0's offset (`struct`);
  - loads IFD0 and, via `ExifIFD` (`0x8769`), the Exif sub-IFD with
    `TiffImagePlugin.ImageFileDirectory_v2` (`_endian` set from the header);
  - maps the same tags the Pillow path already uses (`_EXIF_MAKE`/`_EXIF_MODEL`/`_EXIF_DATE_TAGS`
    in IFD0, `_EXIF_FNUMBER`/`_EXIF_EXPOSURE_TIME`/`_EXIF_ISO`/`_EXIF_FOCAL_LENGTH`/
    `_EXIF_LENS_MODEL` in the sub-IFD), reusing `parse_exif_date`, `_exif_rational_to_float` and
    `_exif_str`.
- `read_image_metadata`: in the `except` branch that today only logs and guesses the mime type,
  call `read_exif_from_tiff` when `is_raw(filepath)` and use its values. The Pillow path is
  unchanged for files it can open (DNG, JPEG, TIFF), so nothing else moves.
- Import `struct` and `PIL.TiffImagePlugin` at module level (Pillow is already a dependency).
