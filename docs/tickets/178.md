## What's wanted

A function that takes the structured answers and returns one numeric rating, organized so it is
easy to modify, and content-versioned so changing it triggers recomputation automatically.

## Design

- `photoapp/ai_score.py` is a small, dependency-free module with a `WEIGHTS` table and
  `score(answers) -> float` in `[0, 10]` (sharpness, composition and exposure weighted most;
  `faces` only counts when `has_people`; `technical_flaws` subtracts; clamped).
- `VERSION` = first 12 hex chars of sha256 of **the module's own source file** — editing a weight, a
  comment or the formula changes it. No manual version bump to forget.
- `ai_score.rescore_stale(conn)` (in 179) recomputes `files.ai_score` from the cached answers for every
  row whose stored `ai_score_version != VERSION`; no network involved. It runs at app start and
  after each `ai_rate` job.
