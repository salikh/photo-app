# 213: Albums endpoint: list, rank, same-name detection

- Type: feature
- Status: done
- Priority: user request 2026-10-10
- Parent: [205](205.md)

## What's wanted

`GET /api/gphotos/albums?name=...`: albums created by this app, ranked by name similarity to the default name and year match. Only app-created albums are visible to the API (see 206).

## Todo

- [x] Response flags exact-name matches so the UI can warn.

## Done

`GET /api/gphotos/albums?name=` (`photoapp/gphotos_rank.py`: similarity + shared-year bonus, `exact` flag), and `/api/export/default_path` now also returns `album` (`export.default_album_name`: folder name, prefixed with a year parent: '2024/trip' -> '2024 trip'; '/' -> 'Photos'). The album API gives no dates, so ranking uses titles only. Tests in `tests/test_gphotos_upload.py`.
