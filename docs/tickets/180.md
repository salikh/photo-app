## What's wanted

An "AI Rate" button in the grid UI that schedules AI annotation jobs for all selected pictures, or all
pictures in the folder when nothing is selected.

## Design

- `POST /api/ai/rate` body `{ids: [photo ids]}` (the client resolves selection-or-view into ids, like Export); enqueues
  one `ai_rate` job per photo's representative file (deduped by the queue). 400 with the message
  "no Gemini API key configured…" when there is no key (the page shows it as a toast).
  Returns `{queued: N}`.
- Button next to Export in the toolbar, label "AI Rate", `title` says what it does; the toast says
  "AI rating queued for N photos" (progress is on the Jobs page).
- Confirmation only when more than, say, 200 photos would be sent (it costs money): `confirm()`.
