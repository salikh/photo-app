- Parent: [006](006.md) Import and ratings

Lightroom `Rating=-1` erases the stars. Plan leans toward keeping `previous_stars` in the DB so un-reject restores them. Needs user confirmation. Note `previous_stars` is not rebuildable from disk.

## Provisional default in use (2026-09-21)

Not yet answered by the user. Implemented the proposed default: rejecting a rated Photo stores its

`ratings.step`) restores it. To change the behavior, edit those two places. Confirm or reverse.

## Decision (2026-09-21)

**Yes: remember the previous stars.** Confirmed by the user; matches what is implemented
(`photos.previous_stars`, set when rejecting a rated Photo, restored by un-reject via `X` or swipe
up). Note it lives only in the app database (see `docs/operations.md` for backups).
