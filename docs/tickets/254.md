# 254: Esc leaves select mode; Ctrl/Cmd+A selects all

- Type: feature
- Status: done
- Priority: user request 2026-10-19

In the grid, Esc leaves select mode (the Select button un-highlights, the selection is dropped); with a
selection made by Ctrl-click outside select mode it still just clears it. Ctrl+A (Cmd+A on a Mac)
enters select mode and selects every photo of the view, loading all pages first, replacing any earlier
selection. Ignored while typing, in the loupe, on non-browse pages and under a modal (the browser's own
select-all stays). Test: `test_escape_leaves_select_mode_and_ctrl_a_selects_everything`.
