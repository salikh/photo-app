# 185: Recognize video files in the library

- Type: task
- Status: open
- Priority: user request 2026-10-08
- Parent: [184](184.md)

## What's wanted

Scanner indexes video files as ordinary files of a new kind.

- `fileinfo.VIDEO_EXTENSIONS` = mp4 m4v mov avi 3gp mpg mpeg mkv mts m2ts wmv webm; `is_video()`;
  `is_image` stays image-only, a new "is media" predicate feeds the scanner/sidecar logic.
  (Library today: ~770 videos, mostly mp4/mov/avi.)
- A video forms its own Photo, grouped by the existing stem rules; XMP sidecars, rating, tags,
  trash, move work unchanged.
- Every video carries the implied tag `video` (same mechanism as ticket 123's `implied_tags`), so
  `tag:video` filters it with no new filter machinery. Not stored in the sidecar.
- `is_video` exposed on the file/photo JSON next to `is_raw`.
