# 198: Popovers open next to the element that opened them

- Type: task
- Status: done
- Priority: user request 2026-10-08
- Refs: `photoapp/static/util.js` (`placeNear`), `photoapp/static/loupe.js`, `photoapp/static/style.css`

## What's wanted

A pop-up that belongs to a control (the loupe's filter switcher, the "⋯" actions menu) should appear
right next to the control that was clicked -- not in the middle of the screen and not stuck at the left
edge.

## Design

- `util.placeNear(node, anchor)`: for a `position: fixed` node already in the DOM; below the anchor if it
  fits, else above, left edges aligned (else right edges aligned), clamped inside the viewport.
- Applied to the filter picker (anchor: the HUD's filter tag, so `openFilterPicker` now renders the HUD
  first, then the panel) and the actions menu (anchor: the clicked "⋯"; its backdrop now only dims
  lightly and the card is the positioned popover).
- Deliberately unchanged: the centered confirmation dialogs (delete, export, move, rename, help). They
  show content (a picture, a form) and are not tied to one control; the Export dialog opened from the
  menu has no anchor left once the menu closes. Say if any of them should be anchored too.
