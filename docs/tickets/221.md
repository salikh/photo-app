# 221: Question — Huge size of an untouched RAF

- Type: question
- Status: done
- Priority: user request 2026-10-11
- Parent: [217](217.md)
- Blocks: nothing (217's other tickets do not depend on it)

## Context

Ticket 085's user-confirmed rule: while a RAW's settings are default, **every** size (including Huge)
comes from the embedded preview — free, no demosaic. A DNG's embedded preview is full size, so Huge
really is full size. A Fuji RAF's embedded preview is only **1920x1280** (the raw is 6032x4028), so
the Huge thumbnail/loupe of an untouched RAF is a 1920 px image — fine for Thumb/Small/Medium
(Medium is 2000, effectively equal), soft when zoomed in the loupe. The pair's camera JPG is full
size (6000x4000), but the Photo's representative is the RAF.

## Question

Should Huge for an untouched RAF be demosaiced (about 7 s once per file, cached, background
`raw_render` job; Thumb/Small/Medium stay on the embedded preview)?

## Options

- A (recommended): Huge demosaics whenever the embedded preview's long edge is below ~75% of the
  RAW's crop long edge; otherwise keep the shortcut. Same rule would automatically apply to any
  other small-preview RAW.
- B: leave it; Huge of a RAF is 1920 px (zoom into the paired JPG for full resolution).
- C: make the Photo's representative the camera JPG when the RAW's preview is small.

## Answer

Yes, Huge preview should be demosaiced from RAF.

## Update 2026-10-11 (found while auditing 220)

For a JPG+RAF **pair** the Photo's representative file is the camera JPG (full 6000x4000), so the
grid and loupe already show a full-size Huge; the 1920 px Huge only appears for a RAF with no JPG next
to it, or when the RAF row of the Files panel is the one being viewed. That lowers the stakes —
option B (leave it) is now less costly than it looked.

## Outcome

Answered "yes" and done. `thumbs._open(..., full=True)` (used for Huge, i.e. `long_edge=None`) demosaics an
untouched RAW through `previews.render` when its embedded preview's long edge is below
`SMALL_PREVIEW_FRACTION` (75%) of the RAW's crop long edge (option A); a DNG's full-size embedded
preview keeps the shortcut, and Thumb/Small/Medium are unchanged. If the demosaic fails the embedded
preview is used. Tests in `tests/test_raf_pairing.py` (fake and `REAL_RAF`).
