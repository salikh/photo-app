# 057: Counts on the filter buttons and keyboard shortcuts for the filters

- Type: task
- Status: open
- Priority: v1 if cheap, otherwise right after 055/056
- Depends on: [055](055.md)
- Related: [056](056.md)

Nice-to-have that makes the filter buttons much more useful while culling: how many photos each mode has in
the current folder, and keys to switch modes without the mouse.

## Counts

- `GET /api/photos/counts?dir=` returns the number of photos of the folder (the ones the grid shows) per mode:
  `all`, `unrated`, `rejected`, `rating:1`..`rating:5`, `fav`, `conflict` (one query with conditional sums;
  honors `one_star_is_unrated`).
- Buttons show the count (`Unrated 312`, `★3 41`); zero-count modes are dimmed but stay clickable.
- Counts update live as ratings change (the client adjusts them, consistent with [056](056.md)) and are
  refetched when the folder changes.

## Shortcuts

Grid view only (in the loupe the digit keys already rate). Proposal, to be decided: `Shift`+digit and
`Shift`+`X`/`U` (unrated) to pick a mode, avoiding `Alt`+digit which switches browser tabs. Shown in the
button tooltips.
