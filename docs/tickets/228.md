## Design

- Mirror the RAW sliders (094/107/108): the Files panel row of a non-RAW still gets an "Edit" block;
  sliders debounce (200 ms) into `GET /api/files/{id}/edit_preview?…` — a Medium-size render of the
  *pending* edits straight from the cached Medium/Huge source, in memory, never written (~40 ms,
  see 224). Shown in `ui.tuning` while hovering the sliders or holding Shift to compare; Save commits
  (PUT), Discard/closing the panel reverts, Reset clears to default.
- Controls (per 225): brightness, contrast, levels (black / gamma / white, a 3-tick slider), per-
  channel levels behind an "Advanced" disclosure, monochrome toggle, sharpen amount + radius;
  optional saturation and an "Auto" levels button.
- The shared RAW/edit panel code should share the debounce/compare/busy plumbing instead of copying
  it; whichever way, RAW behaviour must not change (existing e2e tests stay green).
- A histogram of the preview is nice for levels but not required in v1.
