## What's wanted

Send an image to the Flash-Lite model with a prompt and extract the structured ratings from the JSON
response.

## Design

- `gemini.rate_image(api_key, model, prompt, image_bytes, mime="image/jpeg", transport=None)` →
  `dict` of ints. `POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent`
  with the key in the `x-goog-api-key` header (not the URL, so it never lands in a log), body
  `contents[0].parts = [{text}, {inline_data: {mime_type, data(base64)}}]`,
  `generationConfig = {responseMimeType: "application/json", responseSchema, temperature: 0}`.
- stdlib `urllib` only (no new dependency); `transport(url, headers, body_bytes) -> (status, bytes)`
  is injectable so tests never touch the network.
- Parsing: `candidates[0].content.parts[0].text` → `json.loads`; every schema-required key must be
  present, an integer, and within the schema's range; otherwise `GeminiError` (a blocked/empty
  response carries `promptFeedback.blockReason` in the message). HTTP 429/5xx retried twice with
  backoff; other errors raise `GeminiError` with the status and the API's error message (never the key).
