# 257: quiet /api/jobs polling; job state in the Worker line

- Type: task
- Status: done
- Priority: user request 2026-10-19

The Jobs page polls `/api/jobs` every 1.5 s, which filled the INFO log with uvicorn access lines; they
are now dropped unless the verbosity is >= 1 (filter in `__main__`). The "Worker:" line shows each
running job as `kind file (state, note, elapsed)`, e.g. `video_stabilize clips/a.mp4 (running, pass 2/2:
stabilizing and encoding, 1m 12s)`; `/api/jobs` `active.running[]` gained `state` and `note`.
