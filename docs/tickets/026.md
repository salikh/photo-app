## Result (2026-09-21)

`photoapp/static/{index.html,app.js,grid.js,route.js,state.js,util.js,api.js,style.css}`. Plain ES
modules, no build step. Folders are chips plus a breadcrumb (works on phones without a drawer). The
grid is chunked (pages of 1000) with lazy-loaded `Thumb` images rather than a windowed DOM: fine up
to several thousand Photos per folder. RAW thumbnails that are still rendering retry automatically.
Selection mode (checkboxes, Shift/Ctrl-click) feeds batch rating. Tested in a real Chrome by
`tests/e2e/test_ui.py`.
