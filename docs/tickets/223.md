# 223: Research — which edit settings, and what each costs

- Type: research
- Status: done
- Priority: user request 2026-10-11
- Parent: [222](222.md)

## Method

Measured on this machine (4 cores, Pillow 12.3 / numpy 2.5) with a real 6000x4000 X-H1 JPG
(`/zoo/Pictures/2026/2026-10-11-fuji/DSCF1001.JPG`, 10 MB), best of 3, on a copy downscaled to each
cached size. "Huge" is the full 24 MP image.

| operation (Pillow) | Thumb 300 | Small 1000 | Medium 2000 | Huge 6000 |
|---|---|---|---|---|
| point LUT (brightness, contrast, levels, gamma, **per-channel levels**) | 0.1 ms | 1.2 | 4.8 | 49 |
| monochrome (`convert("L")`) | 0.1 | 1.3 | 5.2 | 53 |
| channel mixer (weighted B&W / colour filter) | 0.3 | 2.8 | 11 | 108 |
| saturation (`ImageEnhance.Color`) | 0.4 | 4.2 | 17 | 157 |
| auto-levels (`ImageOps.autocontrast`) | 0.4 | 2.7 | 10.5 | 101 |
| **unsharp mask r=2** | 2.0 | 27 | 106 | **987** |
| (reference) decode 24 MP JPEG | | | | 239 (149 with DCT-scaled `draft`) |
| (reference) encode JPEG q85 | 0.3 | 3.1 | 13 | 138 |
| (reference) numpy float pipeline instead of LUT | | | 280 | 3250 |

Findings:
- **Everything pointwise is a lookup table** and is effectively free at any size (even Huge is
  50 ms on top of a 240 ms decode). Compose brightness + contrast + levels + gamma + per-channel
  curves into **one 256-entry LUT per channel** — the cost does not grow with the number of
  sliders. Do **not** use a float numpy pipeline (60x slower).
- **Unsharp mask is the only expensive one**, and only at Huge (~1 s, background, cached once).
  It must run **after** the downscale, with a radius scaled to the output size (sharpening a
  24 MP image and then shrinking it wastes the effect), so for Thumb/Small/Medium it costs 2-100 ms.
- Saturation and a channel-mixer B&W are cheap enough to include (<=160 ms at Huge) but add UI; the
  user's list did not ask for them. Auto-levels is a nearly free one-click button (histogram from the
  Small size).

## Recommendation (settings for version 1)

1. **Brightness** (additive offset, ±100) and **contrast** (slope about mid-grey, 0.5-2.0), LUT.
2. **Levels**: black point, white point and a midtone **gamma** (the standard 3-tick slider), LUT;
   applied to luminance (all channels equally) and, optionally, **per channel** (R, G, B each with
   its own 3 points) — one LUT per channel, so per-channel levels cost the same as plain levels.
3. **Monochrome**: on/off, with weights defaulting to Rec.601 luma; optional "filter" presets
   (red/yellow/green/blue) are just different channel-mixer weights. Cost: free to ~100 ms.
4. **Unsharp mask**: amount, radius (stored relative to the image's long edge so every size gets the
   same look), threshold fixed at 3. Included, because it is the one effect that visibly differs on
   a photo and it is cheap at every size the app shows during browsing; Huge costs ~1 s once, in the
   background.
5. Later / not now: saturation (cheap, trivially added to the same model), auto-levels button,
   curves, anything blur-based (clarity, shadows/highlights: 0.8-1 s per blur at Huge),
   noise reduction.

Order of application (fixed): decode+orientation → crop → rotation → downscale → **LUT edits
(levels/brightness/contrast/per-channel)** → monochrome → **unsharp** → encode. LUT before unsharp so
the sharpening sees the final tones; monochrome before unsharp avoids chroma halos.
