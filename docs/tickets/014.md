# 014: Automatic DNG/JPG grouping

- Type: task
- Status: open
- Parent: [003](003.md) Grouping
- Depends on: [012](012.md) Scanner: walk, hash, EXIF, dir-mtime skipping
- Refs: docs/plans/photo-manager-plan.md §4.2; docs/reqs/photo-manager-requirements.md Photo model

Same directory, same case-insensitive basename, RAW + JPG form one Photo: RAW is `original`, JPG is `camera`, `derived_from` the RAW, `link_source='auto'`. Lone files are their own Photo. Representative defaults to camera JPG. Never group across directories (camera counter reuse).
