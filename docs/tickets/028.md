## Progress (2026-09-21)

Deviation from the plan: **LibRaw through `rawpy` replaces `exiftool` + `dcraw`** (pip install, no
system packages; neither tool is installed here). On a real 22 MB DNG the embedded preview is a
full-size 4928x3264 JPEG extracted in 0.02 s, a half-size demosaic takes 0.7 s. So RAW thumbnails
are made synchronously from the embedded preview (`photoapp/previews.py`, `thumbs._open`), and the
background job is only needed for RAWs without a usable preview.

Bug found on the way and fixed: Pillow "successfully" opens a DNG but returns only the 160x120
IFD0 thumbnail, so the scanner had recorded every DNG as 160x120 `image/tiff` (also true of
`file_metadata.py` output). `fileinfo.read_image_metadata` now reads RAW size from LibRaw
(crop size, display orientation) and uses mime `image/x-adobe-dng`. Existing DB rows need a
rescan (`--force`-style revisit, see the scan ticket) to pick up the new dimensions.
Orientation of previews was checked visually against the camera JPG (portrait DNG, flip 5).
